# FallenWare — Releases

Descargas oficiales de **FallenWare**: un studio de Fast Flags para Roblox en Windows.

> Este repositorio contiene **solo los instaladores**. El código fuente es privado.

## Instalación

1. Descargá el instalador desde [Releases](https://github.com/zShift1/FallenWare-Releases/releases) → `setup.exe`
2. Ejecutalo como Administrador (el instalador lo pide solo)
3. Listo — FallenWare queda instalado en `C:\Program Files\FallenWare\`

## Requisitos

- Windows 10/11 (x64)
- .NET 8 y runtime incluidos en el instalador (self-contained, no hace falta instalar nada más)

## Qué hace

- Edición y aplicación en vivo de Fast Flags de Roblox
- Inyección de cambios sin reiniciar el juego
- Presets, configs, mods de cursor y fuente
- Actualización de offsets tras cada update de Roblox

## Datos

Tu configuración vive en `%APPDATA%\FallenWare\` (flags, presets, configs, offsets).
